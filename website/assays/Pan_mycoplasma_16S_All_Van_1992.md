The id's 'Van' is van Kuppeveld; the citation had no author recorded and now does.\nGPO-1FMod is a ONE-BASE modification of the paper's GPO-1, now pinned down exactly. The paper prints GPO-1 as ACTCCTACGGGAGGCAGCAGTA at 16S positions 338-359; the stored sequence is ACTYCTACGGGAGGCAGCAGTA, differing only at position 4, C -&gt; Y. That broadens a fixed C to C/T, so it is a deliberate degeneracy widening consistent with the 'Mod' in the oligo name, not a transcription slip. The published sequence is recorded as modified_from rather than substituted in; no publication of the modified form was found (Europe PMC full text, 2026-10-23), so modification_doi is empty. oligos_designed_here is False because only the backbone is van Kuppeveld's.\nMycoRev1 (GCGRCTGCTGGCACATAGTTWG) is NOT in this paper - the checker found no listed oligo within four edits, and the paper's own reverse primers are GPO-2, MGSO, UUSO and the Mseq set, none of which it resembles. So this pair is a composite: a modified van Kuppeveld forward with a reverse primer from somewhere the seed list does not name. Flagged.</p></details>
