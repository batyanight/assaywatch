# lineage

Splits each assay's records by organism below the target and recomputes
detection for each clade.

A single pooled proportion hides the signal that matters. Published failures are
almost always specific to one lineage, and a clade that makes up 5% of deposits
may make up 100% of cases in one region.

This is the only stage that can change a verdict and not just describe one. If
one adequately sampled clade is significantly below the threshold after
correction for multiple comparisons, it overrides an otherwise reassuring
pooled figure.
