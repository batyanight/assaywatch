# docs/journal/ — the session record

89 dated files, one per working session, from 2026-10-03 onward. Each says what was
measured that day, what was decided, and why. They are **history, not documentation and
not a plan**:

- **Not a to-do list.** Several end in "Next steps" or "Still open". Those sections were
  true on the date in the filename and each carries a line saying so. Open work lives in
  `../../ROADMAP.md`, which is the only to-do list in the repository.
- **Not superseded by date alone.** A later journal does not overrule an earlier one
  unless it says it does. `../INDEX.md` has a `Superseded` section for the ones that are.
- **Not corrected after the fact.** Where a journal recorded a prediction that turned out
  wrong, the prediction stays and the correction is written beside or after it. That is
  deliberate, and it is the most useful property of this directory: it is possible to see
  which of this project's conclusions were arrived at and which were walked back.
  `2026-10-27-thermo-vs-penalty-paired.md` is the clearest example — a result reported at
  p = 0.019 in the morning and corrected to p = 0.071 the same day, once the confound the
  write-up itself had named was fixed.

**Where to start instead.** `../INDEX.md` indexes everything here, grouped by what you
want rather than by date; `../RESUME-HERE.md` is where work actually stopped, newest
first; `../pipeline-architecture.md` is the best single overview of how the tool works.
Open a journal when one of those points at it, or when you want the reasoning behind a
specific number.

Filed here on 2026-10-27. Before that they sat in `docs/` beside the nine reference
documents, so a newcomer met the journals first.
