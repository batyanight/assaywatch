# S4: the identity-aware mispair discount survives the kill test that retired it, now that `reduced` is not a detection for probes

2026-10-27. `strategies/s4-m1-under-s3a.yaml` was written on 2026-10-26 and never run. It
re-asks M1's own question. M1 — `mispair_penalty: {"G:T": 0.0, "T:G": 0.0}`, the G:T
wobble costing nothing — shipped on 2026-10-21 and was reverted on 2026-10-22 for losing
the Leucocytozoon @2016-12-31 catch, by a mechanism the strategy file names exactly: a
discounted record slid from `fail` to `reduced`, and `reduced` counted as detected. The
probe switch that shipped this morning removes that step for probe chemistries. So the
question S4 asks is whether M1's one documented cost is gone.

    python scripts/rescore.py --calls results/2026-10-26/calls.tsv.gz \
        --strategy strategies/s4-m1-under-s3a.yaml --out .tmp/s4

Control: the shipped config replayed over the same table the same day
(`strategies/s3b-conventional-3prime-penalty.yaml` is now the shipped scoring, and its
replay is the S0-equivalent; a literal S0 replay refuses `--expect-identical` against a
table screened under the old penalty, correctly).

**Exactly one case moves**: `INFLUENZA_A_ssRNA_Matrix_gene_recognized_h_2003` at
2010-05-30, a documented failure, from `low coverage` to `declining` — already counted as
caught, now caught by the drift flag rather than the coverage flag. **The Leucocytozoon
@2016-12-31 catch stands.** That is the kill criterion, stated per catch in the strategy
file, and it did not fire.

The 151,076 moved calls decompose as 23,791 `fail → reduced` and 5,000 `fail → detect`
(the discount) plus 9,745 `reduced → detect` and 112,540 `reduced → fail`. The last is the
replay's own rewrite for probe chemistries — `rescore.py` prices the probe switch by
rewriting those rows rather than through `drift`, because that is the only way a replay
can express it — and the shipped pipeline reaches the same answer through
`drift.reduced_not_detected_for`. It is the same rule twice, not an extra change.

## What this does and does not establish

**M1 is no longer refuted by its own kill test.** Its cost on 2026-10-22 was a mechanism,
and the mechanism is gone. On this table and this set it is a strict improvement: the
same catches, one of them promoted to the drift flag, five bench rows fixed, no alarm
added. The literature it rests on — Kwok 1990, Stadhouders 2010: a G:T mismatch barely
costs yield, an A:G or C:C costs a hundredfold — is the identity axis the shipped rule is
still blind to.

**It is priced, not proven, and it is not shipped.** The replay freezes candidate
selection (0 call disagreements over 280,818 rows for S3b today, which is the best
evidence yet that the approximation is small, but S4 moves eight times as many calls).
And the M1 hold is the maintainer's: it was placed on 2026-10-22 for a reason that has
now been measured away, and lifting it is a decision about shipping an identity table
whose only two entries are the easy case. `scoring.mispair_penalty` stays `{}`.

What a maintainer would want before lifting it: a confirming rescreen of the assays that
carry the moved calls, the way S3b had; and the question S4 cannot answer — whether the
rest of the Kwok table (A:A, C:C, G:A, A:G at a *premium*, not a discount) belongs beside
the G:T discount, which is the full identity-aware rule and has never been priced.
