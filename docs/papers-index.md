`papers/` is gitignored because the PDFs are copyrighted, so this file is the durable record of what the project has actually read. Metadata is Crossref's, cached in `papers-index.cache.json` so the index rebuilds offline and so a DOI that changes what it resolves to shows up as a diff.

Regenerate after adding an entry or a PDF:

```bash
python scripts/papers_index.py --out docs/papers-index.md
```

`held` says which format is in `papers/` and whether it is the article or its supplement; blank means the paper still needs to be obtained. A `.xml` is a publisher JATS deposit and a `.txt` is PMC open-access full text; neither is worse than a PDF, and all three are read by `verify_oligos_against_paper`. `assays` lists the registry entries that cite it - blank means the paper is held but nothing has been entered from it yet, which is a to-do rather than an error.
